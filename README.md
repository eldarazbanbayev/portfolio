# Portfolio · Eldar Azbanbayev

Live page: https://eldarazbanbayev.github.io/portfolio/ · Russian: https://eldarazbanbayev.github.io/portfolio/#ru

Prompt engineering portfolio. Main case: **Steppe Hero**, a one-click product video preset built as a ComfyUI graph on OpenRouter models:
one phone photo in, a 5-second golden-hour product shot out. The page covers the pipeline, the test set, three prompt iterations
with an error inventory, image and video model comparisons, and the tooling behind it.

Tooling: [comfyui-openrouter](https://github.com/eldarazbanbayev/comfyui-openrouter), ComfyUI nodes for any OpenRouter image, video and LLM model.
